# 🥝 Kiwi OS

**Version 1.0 — First Official Release**

Kiwi OS is a custom operating system developed by Leevi.

### Features
- Graphical desktop environment
- Custom bootloader
- Mouse support
- File system
- Built-in applications
- Custom icons and wallpaper
- Welcome screen

### Requirements
- QEMU emulator
- NASM assembler
